# zorgame

Клієнт мережі Зоря.нет для конкурсу ZORIA: реєстрація, статус доступу до репозиторію, новини, листи та частини завдання. Надалі виросте в ігровий штаб.

## Вимоги

- Node.js 22.12 або новіший
- npm (залежності фіксує `client/package-lock.json`)

## Встановлення і запуск

```bash
cd client
npm ci
npm run dev
```

Застосунок відкривається на http://localhost:5173.

Збірка і перегляд зібраної версії:

```bash
cd client
npm run build
npm run preview
```

## Сервер

Адреса сервера - налаштування, код правити не треба.

- У застосунку: перемикач «Сервер» у верхній панелі (вибір запам'ятовується в браузері).
- Через змінні середовища: скопіюйте `client/.env.example` у `client/.env.local`.

| Значення `VITE_ZORIA_SERVER` | Адреса |
|---|---|
| `prod` (за замовчуванням) | https://zoria.net/api/v1 |
| `stand` | https://stand.zoria.net/api/v1 |
| `custom` | `VITE_ZORIA_API_URL`, наприклад локальний мок |

Токени й паролі в `.env` і в репозиторій не потрапляють.

## Команди

| Команда | Що робить |
|---|---|
| `npm run dev` | сервер розробки |
| `npm run build` | перевірка типів і збірка в `client/dist` |
| `npm run typecheck` | тільки перевірка типів |
| `npm run lint` | ESLint із перевірками типів |
| `npm test` | тести (Vitest) |
| `npm run gen:api` | перегенерувати типи з `client/api/part1.openapi.yaml` |

## Структура

```
.zoria                  логін у мережі Зоря.нет
client/                 клієнт мережі (React + TypeScript + Vite)
  api/                  контракт OpenAPI частини 1 (MIT, від організаторів)
  src/api/              типи контракту і обмін із сервером
  src/app/              оболонка застосунку, маршрути, вибір сервера
  src/config/           адреси серверів
  src/lib/              спільні утиліти (час тощо)
  src/pages/            екрани
```
